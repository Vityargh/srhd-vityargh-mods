# История изменений / Changelog

## SmartLootAI 0.10 (бета) — 2026-10-28
- Мод больше не привязан к одной сборке игры: при запуске он сам находит нужные места в коде игры. Поддерживаются 2.1.2500 из Steam/GOG и сборка из мода Redux. Если код в этих местах другой, мод не включается и пишет причину в лог.
- Работает вместе с XenoBigGalaxy: убраны три пустых перехвата, один из них совпадал с перехватом XenoBigGalaxy.
- `ActiveJunkCleanup=0` теперь полностью выключает вмешательство мода: цели, выстрелы и решения обычных кораблей остаются как в игре без мода. Мусорщики, уже летающие в сохранении, просто стоят без дела.

The mod is no longer tied to one game build: it locates the game code it needs at startup. `ActiveJunkCleanup=0` now leaves ordinary ships completely untouched.

## SmartLootAI 0.9 (бета) — 2026-10-28
Первый публичный выпуск.
- Обычные корабли убирают лишний лут свободными орудиями, только когда рядом нет врагов.
- Служба мусорщиков: до 10 кораблей, не больше двух в системе, сами перелетают туда, где есть работа. Неуязвимы, без дропа, с бесконечным топливом.
- С экипажем можно поговорить: 34 темы.
- Артефакты, микромодули и ноды не трогаются никогда; квестовые и особые вещи — от 10 000 кредитов за единицу веса; незнакомые игре предметы других модов — всегда; оборудования в системе остаётся до 50 штук.
- Тексты на русском и английском.
- Мод проверяет код игры перед запуском и, если что-то не так, показывает понятное сообщение вместо молчаливого бездействия.

First public release: junk cleanup by ordinary ships, a janitor service you can talk to, protection for everything valuable, Russian and English texts.

## ApplyCrashFix 1.0 — 2026-10-28
- Движок планетарных боёв остаётся в памяти до закрытия игры, поэтому кнопка «Применить» в списке модов больше не роняет игру.
- The game no longer crashes after pressing Apply in the mod list.

## BureauAffordableDesign 1.0 — 2026-10-28
- Кредитная стоимость новых проектов в КБ делится на 10; встроен фикс вылета КБ.
- Design bureau projects cost 10 times fewer credits; includes a design bureau crash fix.
